# Политика безопасности

## Поддерживаемые версии

NeuroHunter находится в активной разработке. Стабильные релизы пока не опубликованы.

Исправления безопасности в первую очередь предназначены для актуальной версии ветки `main`. Поддержка более старых версий не гарантируется.

## Сообщение об уязвимостях

Если вы обнаружили потенциальную уязвимость в NeuroHunter, пожалуйста, сообщите о ней конфиденциально.

**Не публикуйте подробности уязвимости в открытых GitHub Issues до её устранения.** Это поможет снизить риск использования уязвимости другими лицами.

Предпочтительный способ сообщения — функция приватного информирования об уязвимостях в разделе **Security** репозитория, если она доступна.

Если приватное информирование не настроено, свяжитесь с сопровождающим проекта через его профиль GitHub и согласуйте безопасный способ передачи информации.

При сообщении об уязвимости по возможности укажите:

- Краткое описание проблемы.
- Затронутый компонент и версию.
- Шаги для воспроизведения проблемы.
- Возможные последствия и оценку серьёзности.
- Предполагаемый способ устранения, если он известен.

Не включайте в сообщение реальные пароли, токены доступа, персональные данные пользователей или другие секреты. Если для демонстрации проблемы необходимы примеры, используйте тестовые данные.

## Область действия

К вопросам безопасности NeuroHunter относятся, в частности:

- Аутентификация, авторизация и управление пользовательскими сессиями.
- Хранение и обработка паролей, токенов и других секретов.
- Защита персональных данных и пользовательских резюме.
- Обработка загружаемых файлов, включая PDF и DOCX.
- SQL-инъекции, инъекции команд и другие уязвимости обработки входных данных.
- Безопасность API и взаимодействия между сервисами.
- Обработка внешних данных о вакансиях.
- Безопасность взаимодействия с LLM и обработки её результатов.
- Уязвимости сторонних библиотек и зависимостей.
- Небезопасная конфигурация Docker и инфраструктуры приложения.

## Раскрытие информации

Пожалуйста, предоставьте сопровождающему проекта разумное время для проверки сообщения и устранения уязвимости до её публичного раскрытия.

Сопровождающий проекта приложит разумные усилия для рассмотрения сообщения, однако гарантированные сроки ответа и устранения уязвимостей пока не установлены.

Благодарим за ответственное раскрытие уязвимостей и помощь в повышении безопасности NeuroHunter.
